# Dannycastillo Tap

## How do I install these formulae?

`brew install dannycastillo/tap/<formula>`

Or `brew tap dannycastillo/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dannycastillo/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
